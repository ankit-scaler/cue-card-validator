Rules enforced by this validator
  • The file is split into cards at each --- metadata block; every card is validated.
  • --- is only allowed as a card's opening / closing metadata delimiter. Any standalone --- elsewhere is an error, and every opening --- must have a matching closing ---.
  • Metadata keys: mandatory title, duration, card_type (errors if missing); description is optional (warning if missing). No duplicate or unknown keys.
  • Each metadata line is key: value — no space before :, a space after it; values stay on one line.
  • title — required, non-empty, no :, no ---, no emojis. Allowed: letters, digits, spaces, hyphens, and , ? ' " & ( ) [ ]. Nothing else (no full stop).
  • description — optional; if present, value may be empty.
  • duration — required, positive whole number of seconds.
  • card_type — exactly cue_card or quiz_card.
  • Cue card — body content present, with at least one heading.
  • Quiz card — has # Question (with content) and # Choices; at least 2 choices; exactly one correct; correct mark is lowercase [x] (capital [X] is an error).
  • Quiz card ends at its choices. Any content after the last choice — before the next card's --- — is dropped on ingestion → error.
  • Code blocks — should use the ```lang= fence form (advisory warning).
